## 4. App Store — App Privacy 답안

수집하는 데이터: **연락처 정보 → 이메일 주소**, **사용자 콘텐츠 → 기타 사용자 콘텐츠**
(반려견 건강 기록)

| 질문 | 답 |
|---|---|
| 데이터를 수집하나요? | 예 (이메일, 닉네임, 반려견 건강 기록) |
| 앱 기능에 사용? | 예 |
| 사용자에게 연결되나요? | 예 (계정에 연결) |
| 추적(Tracking)에 사용? | **아니오** |
| 제3자 광고/분석 SDK | **없음** |

> 현재 버전은 모든 데이터가 **기기 안에만** 저장됩니다(서버 미연동). 서버 저장 모드로
> 전환하면 이 답안은 그대로 두되, 개인정보처리방침의 위탁(Supabase·Vercel) 고지가
> 이미 반영되어 있는지 확인하세요.

## 7. 배포 명령

```bash
# iOS — 분석·테스트 → IPA → TestFlight
tools/ios-release.sh <TEAM_ID> <KEY_ID> <ISSUER_ID>

# Android — 분석·테스트 → AAB → Play internal 트랙
```

## 8. 이번 버전에서 감춘 기능

Apple 심사 가이드라인 2.1(App Completeness) 대응으로, 아직 실제 동작하지 않는 기능을
`app/lib/config/features.dart` 플래그로 감췄습니다. 구현이 끝나면 플래그만 켜면 됩니다.

| 기능 | 플래그 | 켜기 전 필요한 것 |
|---|---|---|
| 소셜 로그인(카카오·구글·애플) | `Features.socialLogin` | Supabase Auth 프로바이더 설정 + 각 플랫폼 키. **다른 소셜 로그인을 넣으면 Apple 로그인은 필수** |
| 휴대폰 본인인증 | `Features.phoneVerify` | 본인확인기관(NICE·KCB) 계약 |
